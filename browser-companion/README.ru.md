# LUCH Browser Companion · кандидат R1

**В изолированном Chrome расширение работает. Выпуск в production: HOLD.**

Пользователь подключает LUCH по одноразовому коду, сам разрешает конкретную вкладку и может немедленно отозвать доступ. Доступ действителен 15 минут; переход на другой сайт закрывает его. Расширение не требует общих разрешений на cookies, историю, все вкладки и отладчик.

## Подтверждено

- Официальный **Google Chrome for Testing 156**: **10/10** сквозных проверок с реальным MV3 service worker и локальным Broker.
- **Chromium 153**: те же **10/10**.
- До действия пользователя Chrome не позволял читать страницу. После запуска действия расширения через реальную клавиатурную команду выдавал `activeTab`. Подтверждены чтение выбранной вкладки, отказ чужой вкладке, ручной отзыв и отзыв при смене сайта.
- Реальный popup Chrome открылся, а нажатие на его кнопку «Разрешить» через CDP создало ровно один грант в Broker.
- **12/12** локальных защитных тестов, включая отсутствие `Origin` у авторизованного GET и отказ при чужом `Origin`, неверном токене и записи без разрешения.

## Исправлено

Chrome отправлял `GET /extension/jobs` без `Origin`, Broker отвечал отказом и расширение сразу показывало «Не подключено» даже после успешного ввода кода. Теперь GET без Origin допустим только при действующем секретном Bearer-токене, а POST продолжает требовать Origin именно подключённого расширения.

## Пока не проверено

Установка в обычный Chrome Stable пользователя, нажатие мышью пользователем в нативном popup Chrome (автоматизированный CDP-клик проверен), пользовательские Tilda/GetCourse, OAuth/tenant-привязка облачного LUCH, Opera и Firefox, магазин расширений, независимый допуск. На Mac/Xcode/production изменений нет.
