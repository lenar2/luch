# Подключение LUCH к ИИ

[**English**](CLIENTS.md) · [**На главную**](../README.ru.md) · [**Возможности LUCH**](CAPABILITIES.ru.md)

LUCH — самостоятельная MCP-платформа. У каждого приложения-ассистента свой механизм подключения плагинов, OAuth и отображения инструментов. Публичный исходный пакет ещё не означает, что интеграция уже одобрена магазином соответствующего приложения.

## ChatGPT / Codex

У владельца существует действующий приватный плагин **LUCH 0.3.51**. Для публичного распространения подготовлены [манифест и исходные файлы](https://github.com/lenar2/luch-claude-plugin/tree/main/integrations/chatgpt), а также [ZIP-кандидат](https://luch.lenarsalimov.ru/downloads/luch-chatgpt-0.1.6-preview.zip). Отдельное подключение нового пользователя и решение о публикации в каталоге требуют собственных проверок.

## Claude

[Пакет LUCH для Claude](https://github.com/lenar2/luch-claude-plugin) размещён публично. В кабинете Anthropic существует заявка, автоматическое сканирование пройдено; версия ещё не опубликована. Ранее проводилась независимая проверка отдельных пакетов — её результаты относятся к точным проверенным версиям.

## Cursor

[Пакет LUCH для Cursor](https://github.com/lenar2/luch-cursor) доступен на GitHub. Публичный репозиторий не является подтверждением статуса публикации в Cursor Marketplace.

## Gemini CLI

[Расширение LUCH для Gemini CLI](https://github.com/lenar2/luch-gemini) размещено в открытом репозитории. Нужны поддерживаемый клиент и авторизация пользователя.

## Kimi

[Кандидат LUCH для Kimi](https://github.com/lenar2/luch-claude-plugin/tree/kimi-v0.1.6-candidate) подготовлен. Через форму обратной связи Kimi был запрошен путь официальной публикации; подтверждения размещения пока нет.

## MCP-адрес

У действующей приватной интеграции LUCH используется:

```text
https://luch.lenarsalimov.ru/luch/mcp
```

В некоторых проверочных пакетах для сторонних клиентов указан **отдельный ограниченный Public Core MCP**. Это не взаимозаменяемые ресурсы. Используйте адрес из конкретного установочного пакета и предусмотренный OAuth-процесс. Не копируйте чужие токены и не подключайте устройства без разрешения владельца.

## Что проверять при подключении

После разрешённого входа в аккаунт проверьте доступный список инструментов, затем выполните безопасную тестовую операцию на собственном устройстве или в отдельном браузере. Требуется фактический результат, а не только сообщение о постановке действия в очередь.
