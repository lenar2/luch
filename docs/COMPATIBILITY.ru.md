# Где LUCH работает

[← LUCH](../README.ru.md) · [English](COMPATIBILITY.md) · [Подключение](START_HERE.ru.md)

LUCH можно использовать из привычного ИИ-чата. Доступ к сайтам, вашим вкладкам, компьютеру и серверу — это разные способы работы, каждый со своими разрешениями.

## В вашем ИИ

**ChatGPT.** У подключённого аккаунта LUCH работает прямо в обычном текстовом разговоре. Режим Work не нужен. Инструменты доступны только в пределах текущего аккаунта и беседы.

**Claude, Cursor, Gemini CLI.** Для каждого существует отдельная интеграция. Проверьте требования клиента и доступ к инструментам прежде, чем начинать задачу.

[Интеграция ChatGPT](https://github.com/lenar2/luch-claude-plugin/tree/main/integrations/chatgpt/) · [Claude](https://github.com/lenar2/luch-claude-plugin) · [Cursor](https://github.com/lenar2/luch-cursor) · [Gemini CLI](https://github.com/lenar2/luch-gemini)

## Два способа работать с сайтами

**Отдельный браузер LUCH на сервере.** Firefox исследует открытые сайты независимо от вашего компьютера: открывает страницы, следует по ссылкам, читает, вводит текст, нажимает и делает снимки там, где разрешено. В этой сессии нет автоматического доступа к вашим личным аккаунтам.

**Ваш браузер на подключённом компьютере.** Когда нужна уже открытая вкладка или собственная авторизованная сессия, LUCH обращается к разрешённому браузеру на конкретном устройстве.

**История браузеров.** Основатель лично подтвердил работу с Chrome, Opera, Opera Neon, Яндекс Браузером, Microsoft Edge, Brave, Firefox и Safari. Среди сохранившихся технических протоколов есть запуск Opera Neon и чтение вкладок Edge/Brave; глубина документированных проверок по браузерам различается. Это не утверждение об одинаковом полном автоматизированном тесте каждого браузера на каждой системе.

## Windows: разделим три задачи

1. **Вы открываете обычный ChatGPT или другой совместимый ИИ на Windows.** Удалённый LUCH общается по HTTPS/MCP и по архитектуре не требует macOS у пользователя. При наличии подключения и разрешений серверные задачи должны быть доступны. Независимый Windows end-to-end тест нового пользователя ещё не проведён.
2. **LUCH исследует сайт в серверном Firefox.** Этот браузер выполняет работу на сервере, поэтому не зависит от того, открыли ли вы ChatGPT на Windows или macOS.
3. **Вы хотите, чтобы ИИ управлял окнами и программами самого Windows-компьютера.** Для этого нужен отдельный совместимый Windows-компонент, подключение устройства и системные разрешения. Поддержка локального управления macOS не доказывает поддержку Windows.

Разница важна: отсутствие проверки третьего сценария нельзя превращать в утверждение, что LUCH недоступен из Windows-чата.

## Остальные устройства

**macOS.** В подключённой среде подтверждены разрешённые действия с файлами, окнами, экраном и программами Mac. Доступ зависит от конкретного устройства и его разрешений.

**Linux-сервер.** Подтверждены серверные команды и отдельный браузер. Это не обещание управления любым графическим Linux-компьютером.

**iPhone и Android.** Для отдельных функций iPhone есть интеграции, но универсальное управление всеми приложениями телефона не заявлено. Полное управление Android также не подтверждено.

## Первое подключение

Для разрешённых серверных и веб-задач отдельное приложение LUCH на вашем компьютере не требуется. Для личных вкладок, файлов и программ нужно подключить конкретное устройство. Публичная доступность исходного кода не означает, что самостоятельная регистрация и OAuth уже подтверждены для всех новых аккаунтов.

Начните без изменения данных: *«Сравни эти две открытые страницы и покажи, откуда взял вывод».*
