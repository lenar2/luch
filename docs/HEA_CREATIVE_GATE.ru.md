# LUCH — независимый творческий допуск HEA v1.0

**Дата: 7 ноября 2026. Канонический стандарт публичного человеческого опыта.**
[English](HEA_CREATIVE_GATE.md) · [Бланк проверки](HEA_REVIEW_PACKET.ru.md)

## Мой принцип
Я создаю LUCH ради нового качества работы человека с ИИ. **Наличие текста, рабочего кода, правильных ссылок и успешной публикации не означает высокого Human Experience.**

Публичная страница достойна LUCH, только если незнакомому человеку **за 10 секунд понятна реальная польза, хочется попробовать и виден честный первый шаг**. Если этого нет — **HOLD**, даже при техническом PASS.

Применяется к GitHub README, сайту, клиентским страницам, интерфейсам подключения, каталогам, визуалам, рекламным демонстрациям и публичным историям. Без исключений для «совсем небольшой правки» в тексте, меняющей впечатление.

## G0 · Доказательство прежде дизайна
До композиции автор предъявляет один проверяемый человеческий сценарий: **запрос → разрешённые ресурсы → реально выполненные действия → наблюдаемый результат → первичные ссылки/артефакты**.

- Вымышленное выполнение, неподтверждённые зелёные галочки, приписывание действия другому ИИ-клиенту — автоматический `NO_GO`.
- Пример возможной работы обозначается **сценарием**, а не доказанным кейсом.
- Публичный голос LUCH — **моё первое лицо**, без рассказа обо мне как о третьем лице, личных внутренних подробностей и ложных дословных цитат.
- Подтверждённое, условно доступное и будущее не смешиваются; ограничения не подменяют собой ценность продукта.

## G1 · Творческое качество (0–4, не от автора)

| Измерение | Что должен испытать человек |
| --- | --- |
| **Ясность** | За 10 секунд понятно, что даёт LUCH и кому |
| **Притяжение** | Самому хочется получить подобный результат |
| **Отличие** | Видна разница между ответом ИИ и настоящим действием через LUCH |
| **Достоверность** | Реальная работа отделена от сценария и обещания |
| **Начало** | Есть реальный первый шаг без замкнутых CTA и вымышленной регистрации |
| **Мастерство** | Самобытная композиция, сильный язык, ритм, визуальная чистота, доступность |

Шкала: 0 — обман/опасность; 1 — непонятно; 2 — функционально, но желания нет; 3 — убедительно; 4 — хочется попробовать и есть ясная, наблюдаемая причина. Рецензент оставляет конкретный аргумент для каждой оценки.

**Допуск:** ни одного балла ниже 3; по **Притяжению** и **Отличию** обязательно 4. Усреднять провал нельзя. Авторский самоаудит, даже очень строгий, **не является** независимым одобрением.

## G2 · Слепой первый просмотр реальных людей

Не менее **пяти новых представителей целевой аудитории**, не участвовавших в создании, смотрят один и тот же **отрендеренный снимок точной версии** 10 секунд. Без вступительной рекламы, объяснений и подсказок.

Дословно фиксируются ответы каждого: «Что это?», «Что вы получите?», «Куда нажмёте сначала?», «Хочется попробовать? Почему?». Затем наблюдается **первый реальный клик** (или тупик), без ведения за руку.

Минимум: **4/5** понимают конкретную пользу, **4/5** находят первый осмысленный шаг, **4/5** самостоятельно хотят попробовать и называют причину. Критическая ложная уверенность в доступности/результате — блокер, а не «один допустимый минус». Подсчитанное без реальных участников — `NOT_RUN`, не `PASS`. Пять человек — порог качественной проверки, не научная оценка конверсии.

## G3 · Действительно независимое вето

Художественный критик **не должен быть автором, редактором или человеком, заинтересованным в выпуске конкретной версии**. Он видит точный SHA, страницу без питча автора и реальные материалы, оценивает шесть осей и имеет право на `REWORK` или `NO_GO`. Отдельно кто-то неавторский наблюдает холодный тест (допускается тот же критик, если не подсказывает).

Для `GO` нужны:
1. Мотивированная оценка и **проверяемый автор комментария**, отличный от автора материалов.
2. Настоящие записи холодного просмотра и результаты кликов.
3. **Моё отдельное разрешение** на выпуск **того же точного SHA**.

Роли не создаются клонированием ответов автора. Псевдоним GPT/Claude в Peer Bus сам по себе не подтверждает независимость. После любого редактирования сообщения, композиции или CTA нужно заново проверить изменённую версию. Независимое `NO_GO` не отменяется техническим тестом или решением автора.

## G4 · Визуальная и техническая правда

Нужны реальные рендеры **320 / 390 / 768 / 1440 px**; скриншоты без вылезания текста, скрытого CTA, рваного ритма, проблем с клавиатурой и нечитаемых подписей. Проверяются контраст, читаемость, смысловые альтернативы изображений и обе локали. Это ограниченная ручная проверка, не автоматическая WCAG-сертификация.

Сверяются источники, первичные доказательства, утверждения о функциях, статусы интеграций и **реальный** путь подключения. Технический QA (ссылки/сборка/откат/HTTP) обязателен отдельно — он **никогда не заменяет** G1–G3.

## Решение и право на публикацию

`DRAFT → AUTHOR_REWORK → INDEPENDENT_CRITIQUE → COLD_TEST → FOUNDER_GO → PUBLISH → POST_RELEASE_CHECK`

Состояние нового публичного HEA-релиза **по умолчанию HOLD**. Нет точного артефакта, подписи рецензента, ответов реальных людей, успешного визуального QA или моего разрешения → **NO_GO**. Исправление — в отдельной ветке, затем новая независимая проверка. Срочное исправление безопасности без новых публичных заявлений можно оформить отдельно с ограниченным объёмом, но не использовать для обхода творческого допуска.

## Что сейчас технически не защищено

Проверено: в четырёх публичных репозиториях LUCH **нет активных GitHub rulesets**, блокирующих прямые обновления `main`. Доступное соединение GitHub не умеет менять эти настройки. **Этот документ вводит обязательный ручной HOLD, а не уже работающий технический запрет.** Никаких заявлений об автоматическом блокировании.

Для настоящей защиты уполномоченный администратор должен отдельно включить: **только PR**, запрет прямого/force push в `main`, независимый review отличным от автора аккаунтом, запрет обхода; затем подтвердить защиту безопасным отказным тестом. GitHub Actions для этого **не использовать**.

**R1–R4:** уже опубликованы, но не имеют доказанного творческого PASS по G1–G3. Технический QA их не реабилитирует задним числом. **Следующий публичный выпуск LUCH: HOLD**, пока реальные независимые свидетельства не существуют.
