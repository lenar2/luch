# Статус подключения и распространения LUCH

[**English**](RELEASE_READINESS.md) · [**На главную**](../README.ru.md) · [**Возможности**](CAPABILITIES.ru.md)

LUCH **реально работает в подключённой среде владельца**. Это важно отличать от статуса отдельных магазинов плагинов и от проверки самостоятельного подключения нового аккаунта.

## Что уже подтверждено

- Международный сайт LUCH доступен на английском и русском.
- Публичные клиентские исходники доступны для Claude, Cursor и Gemini CLI; подготовлен кандидат для ChatGPT/Codex.
- Действующая приватная интеграция ChatGPT используется владельцем.
- Сервер LUCH отклоняет анонимные MCP-запросы: наблюдался HTTP 401. Это проверка отказа без авторизации, не полная проверка OAuth.
- У пакета Claude пройдено автоматическое сканирование Anthropic. Ранее для других точных версий пакета проводились внешние проверки с замечаниями.

## Что требует отдельного подтверждения

**Новый независимый пользователь:** самостоятельная регистрация → вход через OAuth → привязка собственного устройства → разрешённая операция → невозможность доступа к ресурсам другого пользователя → отзыв доступа. Успешное подключение владельца не заменяет этот тест.

**Магазины:** наличие пакета на GitHub, сканирование, отправка заявки, одобрение и фактическая публикация — отдельные события. Нельзя считать их одним статусом.

**Агенты:** работающая очередь Peer Bus не означает, что целевая модель прочитала сообщение и начала задачу. Нужен фактический ответ или результат.

## Что это значит для пользователя

LUCH — действующая платформа с широким набором инструментов, а не несуществующий прототип. Доступность конкретных функций зависит от аккаунта, устройства, разрешений и поддерживаемого ИИ-клиента. В документации к каждому клиенту указана его отдельная ситуация.
