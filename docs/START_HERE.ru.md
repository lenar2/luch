# Начните с ИИ, которым уже пользуетесь

[← LUCH](../README.ru.md) · [English](START_HERE.md) · [Статус доступности](https://luch.lenarsalimov.ru/ru/status/)

**Сначала честная проверка:** LUCH работает у подключённых пользователей, но самостоятельный путь произвольного нового пользователя ещё не подтверждён. Поэтому обещать всем кнопку «подключиться сейчас» было бы неверно.

| Ваш ИИ | Где начать | Что известно |
| --- | --- | --- |
| **ChatGPT** | [Кандидат интеграции](https://github.com/lenar2/luch-claude-plugin/tree/main/integrations/chatgpt/) | Частная интеграция основателя работает; в публичном каталоге OpenAI пакет **не подтверждён** |
| **Claude** | [Адаптер Claude](https://github.com/lenar2/luch-claude-plugin/) | Код опубликован; доступ аккаунта и одобрение платформы проверяются отдельно |
| **Cursor** | [Адаптер Cursor](https://github.com/lenar2/luch-cursor/) | Есть инструкция локальной установки; нужны разрешённый аккаунт и OAuth |
| **Gemini CLI** | [Расширение Gemini CLI](https://github.com/lenar2/luch-gemini/) | Есть команды установки, но независимый полный путь нового пользователя не доказан |
| **Kimi** | [Ветка-кандидат](https://github.com/lenar2/luch-claude-plugin/tree/kimi-v0.1.6-candidate) | Не подтверждённая публикация в каталоге |

## Если доступ к вашему аккаунту уже открыт

1. Откройте README конкретного ИИ. Войдите штатным способом — не используйте чужие ключи.
2. Выберите ровно тот браузер, файл или сервер, который разрешён. Недоступное устройство не подменяется другим.
3. Начните без записи: *«Прочитай эту открытую страницу и перескажи со ссылкой».*
4. Посмотрите фактический результат. Публикацию, удаление и другие важные действия подтверждайте отдельно.

## Если доступа ещё нет

Публичные исходники можно изучить, но **установка не открывает аккаунт**. Не используйте закрытые адреса и чужие учётные данные. Смотрите [текущий статус](https://luch.lenarsalimov.ru/ru/status/) и [поддержку](https://luch.lenarsalimov.ru/support/). Пробел самостоятельного подключения явно отмечен в [критериях выпуска](RELEASE_READINESS.md).

[Один подтверждённый случай работы у основателя](REAL_WORK.ru.md) показывает возможности без обещания, что они уже доступны всем.
