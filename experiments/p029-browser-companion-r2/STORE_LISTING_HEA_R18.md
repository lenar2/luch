## Русский — карточка для покупателей

**Название:** LUCH Browser Companion

**Краткое описание:** Ваш ИИ понимает выбранную вкладку Chrome. Чтение и действия — только с вашего разрешения.

**Подробное описание:**

Ваш ИИ может помогать не только словами — но и с открытой страницей браузера.

LUCH Browser Companion связывает выбранную вами вкладку Chrome с вашим привычным ИИ, если он поддерживает подключение LUCH через MCP. Не нужно переносить большие фрагменты текста вручную, создавать отдельный чат LUCH или получать личный API-ключ OpenAI.

**Что можно делать**

• **Разобраться в странице.** Разрешите чтение статьи, инструкции или документации и попросите ИИ объяснить сложное, найти главное или собрать краткий итог.

• **Найти нужное быстрее.** Попросите ИИ изучить разрешённую вкладку, найти важный раздел, ссылки, таблицы или элементы страницы.

• **Перейти от анализа к действию.** Поддерживаемые клики, ввод текста и навигация доступны только после отдельного разрешения на взаимодействие с этой вкладкой — и если ваш ИИ-клиент поддерживает такие инструменты.

• **В любой момент остановить доступ.** Отзовите разрешение для одной вкладки или полностью отключите браузер. Остальные страницы не становятся доступными автоматически.

**Подключение — шаг за шагом**

1. Установите LUCH Browser Companion в Chrome.
2. В своём совместимом ИИ подключите LUCH по защищённой ссылке `https://api.lenarsalimov.ru/luch/browser/mcp` и подтвердите вход. Инструкция есть в расширении.
3. Попросите ИИ: «Создай код подключения браузера». Введите восемь цифр в расширении.
4. Откройте нужную страницу, нажмите значок LUCH и разрешите чтение именно этой вкладки. Для действий на странице потребуется ещё одно разрешение.

**Вы решаете, чем делиться**

LUCH не получает автоматический доступ ко всем вашим вкладкам. Чтение, действия и точное управление указателем — отдельные разрешения. Необязательный обзор названий открытых вкладок тоже включается отдельно.

**Важно перед установкой**

• Нужен ИИ-клиент и тариф/рабочая среда с поддержкой пользовательского удалённого MCP. Не все аккаунты ChatGPT предоставляют одинаковый доступ к таким инструментам. Одна установка расширения не подключает ChatGPT автоматически.

• Chrome запросит мощное дополнительное разрешение отладчика (`debugger`) только если вы сами включите режим точного указателя. Для обычного чтения вкладки это разрешение не требуется.

• Содержимое разрешённой страницы по вашему запросу может передаваться через защищённое облако LUCH вашему ИИ. Не разрешайте доступ к конфиденциальной странице, если не готовы поделиться её содержимым.

**Это ваш браузер. Ваш ИИ. И ваши разрешения.**

## English — customer-facing listing

**Name:** LUCH Browser Companion

**Short description:** Help your connected AI understand a Chrome tab you approve. Reading and actions require separate permission.

**Detailed description:**

Your AI can do more than answer questions. Give it the context of a page you choose — without repeatedly copying and pasting its contents.

LUCH Browser Companion links an explicitly approved Chrome tab to your existing, compatible AI conversation. You don't need a separate LUCH chat or a personal OpenAI/Anthropic API key.

**What you can do**

• **Understand a page.** Approve an article, guide or documentation page and ask your AI to summarize it, explain a concept or find the most useful details.

• **Explore the page.** Identify headings, links, tables, visible information and supported page elements in the tab you choose.

• **Move from insight to action.** Supported clicks, text entry and navigation require a second, explicit per-tab interaction approval and a compatible AI host that supports those tools.

• **Stay in control.** Revoke access to one tab or disconnect the browser. You do not share all your open tabs by default.

**Connect in four steps**

1. Install LUCH Browser Companion in Chrome.
2. In an eligible AI host, connect the secure LUCH remote MCP endpoint `https://api.lenarsalimov.ru/luch/browser/mcp` and approve OAuth. The extension links to detailed instructions.
3. Ask your AI to create a browser pairing code. Enter the eight digits directly into the extension.
4. Open a page, click the LUCH extension and approve Read for that tab. Approve Interaction separately only if you need it.

**Permission is the starting point**

You decide which tab may be read, which permitted actions may be performed, and when access ends. An optional overview of all tab titles and addresses requires separate consent. Advanced precise-pointer actions use Chrome's powerful `debugger` permission and require additional per-tab enablement.

**Before installing**

• Your AI app, plan and workspace must support connecting a custom remote MCP server. Features vary by provider and plan. Installing this extension does not automatically add tools to every ChatGPT account.

• Chrome asks for the optional debugger permission only when you explicitly enable precise-pointer control. Normal tab reading does not require it.

• When you ask your AI to read approved content, page data may travel through LUCH Cloud to the connected AI provider. Avoid approving sensitive pages without reviewing the privacy policy.

**Your AI. Your browser. Your permission.**

## HEA review: new user's perspective

**10-second comprehension:** The first sentence must describe the result (AI understands a chosen tab); never open with MCP, OAuth, tools or a platform inventory. The requirements are still visible before installation.

**Reasons to install:** Saves repetitive copy/paste, explains and explores a page, may act when separately authorized. Concrete realistic examples, no unproven claims of purchases, site-wide autonomous browsing, all-plan compatibility or mouse control across the OS.

**Reasons to hesitate:** An unfamiliar brand, an intimidating optional `debugger` permission prompt for advanced pointer mode, multi-step OAuth + code enrollment, cloud processing of page data, host-plan eligibility. Aesthetic artwork alone cannot erase those legitimate concerns. The listing and screenshots must answer them.

**Visual path:** A small, legible icon and 440×280 promo tile; a 1400×560 optional marquee; at least one genuine 1280×800 app screenshot; explanatory image(s) can accompany but must not pretend to be real UI. Brand visuals stay in deep mineral teal, refined soft light, clear typography; no fabricated product outcomes.

**First-use popup fix R18:** The original popup told a person who had already installed the extension to install it again, and showed the internal `browser_companion_pairing_create` name too early. Updated to say 'connect existing AI → ask AI to create a code → enter eight digits', with internal tool name relegated to help text.

## AI/agent perspective

- Must discover `browser_companion_status` and supported device/tab tools from an authorized MCP connection, never hallucinate availability.
- Must ask for one-time code through `browser_companion_pairing_create` only when user requests pairing; the owner enters the secret directly in Chrome.
- Must choose a real online device and an explicitly approved tab target; `browser_list_approved_tabs` should return target IDs without requesting access to all open tabs.
- Must not infer interaction approval from read approval, escalate to debugger/pointer or bypass a host's account/plan limits.
- Must handle no device, revoked tab, expired code and unsupported host access with direct plain-language remediation, not a pretend successful call.
- Must never claim that ZIP packaging, GitHub release and Chrome Store publication are the same event.
