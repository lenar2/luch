# R8.4 facilitator kit
This is a prospective study instrument, not a result. The exact product under test is commit 4c6c0cdc55b1f7fcbd7aa3e319110d1cc528a44a. The R8.4 commit adds study files only. Do not publish Home, alter source product behavior, recruit from personal contact lists or claim the smoke test is a human.
1. Independent facilitator and developer grader review PROTOCOL.md and approve/freeze it, assignment schedule, rubric, candidate and private evidence retention before exposure. Twelve participants is a proposed pilot design, not a sample-size proof.
2. On a separate authorized Linux workstation with Python 3, Node 18+, openssl, Chromium and playwright-core available, open one arm per session from the repository root:
       node home/study/r84/run_trial.cjs browser A
       node home/study/r84/run_trial.cjs luch B
   The launcher opens a fresh ordinary browser for the baseline, or genuine isolated Home for LUCH, including local copies of terms/privacy. No AI, shared production session, external reporting or real credentials. Both local listening sockets are loopback; a browser-only resolver maps the LUCH hostname to the local TLS edge. The local self-signed cert is accepted only in the isolated LUCH context; remote website checks by the backend retain real TLS validation. No production writes. Main site links outside Home/legal pages are intentionally unavailable. Run one arm at a time. Closing the browser removes the temporary stage DB and TLS files; never preserve real passwords or recovery codes. Facilitator must test the headed launcher on their workstation before exposing participants (only headless smoke executed here).
3. Record paired timings and scores privately using OBSERVER_RECORD.md, including failures and withdrawals; do not commit private records. Run python3 home/study/r84/score.py < private-observations.json. The calculator cannot authenticate participants or approvals and never authorizes product readiness.
4. Only publish consented de-identified aggregates after independent evidence review. Any real-site tasks require separately agreed scope. Pilot success does not equal market validation.
