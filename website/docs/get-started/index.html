LUCH · Public Core

Connect LUCH

LUCH exposes a protected remote MCP endpoint for AI hosts that support remote MCP tools. This guide describes the public client, not a private administrator or founder endpoint.

Remote MCP URL

https://api.lenarsalimov.ru/luch/core/mcp

Unauthenticated calls are rejected. Authorized access uses OAuth; the protected-resource metadata endpoint is https://api.lenarsalimov.ru/.well-known/oauth-protected-resource/luch/core/mcp.

Before connecting

  1. Use an account that has been granted access to LUCH Public Core. General self-service registration and independent new-user device pairing have not yet been verified or opened broadly.
  2. In your compatible AI host, add or install the LUCH client plugin and follow the host's supported OAuth permission flow.
  3. Review the grants and request a list of available LUCH tools. Tool availability depends on account, host, device state and configured permissions.
  4. Begin with an authorized read-only task. Review effects before approving commands, browser changes or other modifications.
  5. Disconnect or revoke access when finished. Check that the affected device is no longer reachable under the revoked grant.

What installation does not do

Installation does not pair your Mac or phone, create an account, bypass consent or grant access to private owner tools. Skills included in the package are instructions; they do not imply that every corresponding API is available.

Current capability boundaries

Public Core is a limited account-scoped service. Cloud browser access, local desktop execution, file operations and integration-specific features are provided only when they are actually enabled and verified for the particular user. LUCH iPhone and multi-agent orchestration are not generally released through this plugin.

Troubleshooting

HTTP 401 typically means authentication is required. A paired device may be offline or lack a requested capability. For help use Support. Do not send bearer tokens or secrets to public support channels.
