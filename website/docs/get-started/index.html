Different AI clients support different connection methods. Some connections are available only to enabled accounts while new-user setup is being validated. Check current availability or get help if you're unsure where to begin.

For developers: remote MCP and sign-in details

Compatible AI hosts can use the protected MCP endpoint https://api.lenarsalimov.ru/luch/core/mcp. Authentication uses OAuth and account-specific permissions. The protected-resource metadata endpoint is https://api.lenarsalimov.ru/.well-known/oauth-protected-resource/luch/core/mcp. Connecting the client does not automatically pair a computer or grant access to private tools. Never send tokens to support channels.
