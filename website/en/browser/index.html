Two ways LUCH can reach the web

01

A separate browser

For public-site research, LUCH can open an isolated browser on a server. Your Mac doesn't need to be online.

02

Your own browser

For signed-in personal pages, access depends on a connected computer and explicit permissions. This is a separate mode.

03

An outcome you can check

Navigation, typing, screenshots and page checks can be available where authorized. Sensitive actions need specific intent.
