Something you can inspect

01 — 05

From intention to completed work

01

Understand the real problem

The published LUCH site and GitHub source were inspected. The request was about human experience, not how many components existed.

02

Prepare before publishing

English and Russian pages were redesigned on a separate branch, without using the Mac.

03

Test and correct

32 pages were checked at four viewport widths. Horizontal overflow on a 320px display was detected and fixed.

04

Release with permission

After the founder authorized release, GitHub and the live site were updated, with a backup. The public commit and release record are available.

05

Keep the critical eye

A later self-audit identified weak onboarding and an unconvincing hero. That is a reason to improve the work, not conceal its limits.

What this case proves

An actual chain from a human request to permitted server and GitHub work, ending in an inspectable publication, with the Mac excluded.

What it does not prove

Self-service onboarding of a new customer, every AI host working equally, independent security certification or final design excellence.
