GET STARTED

A clear path from request to action.

LUCH is already operational for enabled accounts. Connect it through your supported AI client and approve the resources you want the assistant to work with. Self-service availability depends on your host and account.

01

Choose where you use AI

LUCH already works with the founder’s ChatGPT setup. Separate public packages exist for Claude, Cursor and Gemini CLI; each has its own distribution and onboarding state.

02

Authorize your LUCH account

Connect using the sign-in flow supported by your AI host and LUCH account. New-account onboarding is assessed separately from existing users.

03

Select the resource

Pair a computer or server, or request an isolated browser session. Grant only the access the task actually requires.

04

Watch, finish, disconnect

Check the actual outcome. Release browser sessions and revoke device access whenever you choose.

Public client packages and support differ between hosts; check the individual client page before connecting.
