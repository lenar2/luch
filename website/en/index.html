Keep the AI you know. Give it real work to do.

LUCH has already been used for real work in ChatGPT, Claude and Grok. In ChatGPT, it works in ordinary chats and Work with an authorized connection. Cursor and Gemini CLI have separate ways to connect; the exact tools depend on the client and permissions.

How to connect ↗

Browsers. The project has used Chrome, Opera, Opera Neon, Yandex Browser, Edge, Brave, Firefox and Safari. Personal tabs require a connected computer; public sites can use server-side Firefox.

Mac. On a connected Mac, LUCH can work with the screen, files, windows, apps and terminal within the permissions you grant.

Linux. On an authorized server, LUCH can run bounded commands, inspect files and use a browser independently of your computer.

Windows. Remote tools are expected to work from a compatible AI client over HTTPS; dedicated Windows testing is still outstanding. Controlling apps on the Windows PC itself needs a separate component.
