TOOLS FOR THE THINGS YOU WANT TO DO

Your work doesn't end at the chat.

When your AI needs a website, a document or a computer to help with a task, LUCH can connect the tools you choose. You see the work and decide what happens next.

WHAT LUCH CAN HELP WITH

Different tools. One meaningful task.

Choose what you want to accomplish. The details below show which tools can help and what access each one needs.

01 / BROWSERS + WEB APPS

Work across the web

Navigate real websites and web apps, inspect page structure, click, fill forms, upload or download files, and capture what happened. Use an isolated cloud browser or a permitted local browser session.

Owner and server browser workflows active
02 / COMPUTER CONTROL

Use the computer you authorize

Work with the screen, windows and supported applications on a paired Mac — using mouse, keyboard, accessibility and clipboard controls where enabled.

Requires a paired machine and OS permissions
03 / FILES + DOCUMENTS

Put working knowledge to use

Find, read, compare and organize approved files and documents; prepare or update materials with explicit authorization and safeguards against stale writes.

Available through supported file and device connections
04 / DEVELOPMENT + INFRASTRUCTURE

Take technical work from issue to evidence

Combine GitHub source, branches and pull requests with bounded terminal commands, paired computers and named servers to investigate, prepare changes and inspect real results.

GitHub and permitted server connections
05 / AI AGENT COORDINATION

Connect work across AI contexts

Peer Bus carries task messages, receipts and shared state. Chat Bridge can address supported ChatGPT and Claude sessions; live model execution and availability are checked separately.

Peer Bus available; chat targets conditional
06 / WORK CONTEXT

Bring more of your work into the task

Where supported, your AI can read relevant information from connected services. GetCourse currently supports read-only access.

GetCourse: read-only in connected accounts
07 / DESIGN + FIGMA

Connect design to implementation

Figma has a separate connector and LUCH has a bridge development track. A complete production LUCH-to-Figma authoring flow is not claimed yet.

Integration track; not universal end-to-end
08 / APPLE NOTES

Bring personal notes into context

Search and read selected Apple Notes, then create or update notes where the connected device and explicit permissions allow it.

Paired-device tools; permissions required
09 / PHOTOS + MOBILE

Use selected personal media

Search authorized photo sources, preview or export permitted media, and use selected cached iPhone content. Full remote control of native iPhone apps is a separate build.

Photo access available; mobile subset
