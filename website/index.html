Compatibility

Your AI.
Your tools.

LUCH can act where your account is connected and authorized. Its isolated server browser is distinct from your personal, signed-in tabs.

Ordinary ChatGPT conversation

I use LUCH inside normal ChatGPT text chats. Work mode is not required. Claude, Cursor and Gemini CLI have their own integration paths.

Browsers

An isolated Firefox browser on the server can research public pages. Existing signed-in tabs need an authorized local browser; Chrome and Opera have been exercised in my environment.

Computers and servers

Authorized macOS computer actions and Linux server work have been demonstrated. Full Windows, iPhone and Android device control is not claimed.

Connection

An enabled chat can use web/server tools without a separate desktop app. Local files and apps require device pairing. New-account access is assessed separately.
