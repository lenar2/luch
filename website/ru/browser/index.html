Два способа работать с вебом

01

Отдельный браузер

Для исследования публичных сайтов LUCH может открывать изолированную браузерную сессию на сервере. Ваш Mac для этого не нужен.

02

Ваш браузер

Для страниц в вашем аккаунте нужен подключённый компьютер и соответствующее разрешение. Это другой тип доступа.

03

Результат, который видно

Навигация, ввод, снимки и проверка страницы доступны там, где разрешены. Чувствительные действия требуют отдельного намерения.
