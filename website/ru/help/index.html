Короткие ответы

01

Могу ли я пользоваться бесплатно?

Core предназначен для бесплатной работы с инструментами при ограничениях безопасности и ресурсов.

02

Будет ли ИИ управлять всем компьютером?

Нет. Только разрешёнными функциями поддерживаемого подключённого устройства.

03

Нужно держать Mac включённым?

Для изолированного серверного браузера — нет. Для доступа к самому Mac — да.

04

Могу ли я зарегистрироваться самостоятельно?

Полный самостоятельный путь нового пользователя пока не подтверждён. Проверяйте доступ конкретного клиента.
