LUCH · Security

Security and trust

LUCH enforces account-aware authentication and permission boundaries for its public MCP interface. The client package does not itself grant hardware, browser, server or file access.

Observed controls

  • The public HTTPS MCP endpoint denies anonymous tool requests with an authentication challenge.
  • Tool access depends on the current user identity, paired devices and available grants.
  • Some browser sessions run in isolated managed environments; availability is configuration-dependent.
  • Account and device state are maintained separately from the public Apache-2.0 client repository.

Current limitations

LUCH has not completed independent public multi-user A/B authorization and full onboarding validation. This page does not claim external certification, a security audit or zero-risk execution. Do not enable sensitive accounts or destructive actions without appropriate testing, permissions and backups.

Report vulnerabilities

Use private vulnerability reporting in the public client repository. Avoid posting exploit details or credentials in public Issues.
