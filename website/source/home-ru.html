Оставайтесь в привычном чате.

LUCH работает прямо в обычном текстовом разговоре ChatGPT у подключённого аккаунта, без режима Work. Для Claude, Cursor и Gemini CLI предусмотрены отдельные интеграции.

Как подключить ↗

В проекте использовали Chrome, Opera, Opera Neon, Яндекс Браузер, Edge, Brave, Firefox и Safari. Для ваших вкладок нужен подключённый компьютер; открытые сайты можно исследовать в серверном Firefox.

Из Windows-чата удалённые инструменты LUCH должны работать при подходящем подключении: они используют HTTPS и не зависят от ОС пользователя. Отдельный Windows E2E ещё не завершён; управление локальными программами Windows требует специального компонента.
