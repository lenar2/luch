LUCH · Help and support

Support

Use these working channels for LUCH client questions, incident reports and technical support. LUCH Core currently has limited access; features and onboarding differ across accounts.

General support

Report installation problems, missing tools and documentation issues in the public GitHub tracker. Do not post sensitive information.

Open a support issue

Confidential report

Report vulnerabilities or make a private privacy/data request through GitHub's private vulnerability reporting channel. Mention the request type in the title.

Open private reporting

Useful details for a report

Include the AI host, LUCH plugin version, tool name, approximate time, whether the device was paired and online, and a redacted error message. Never share OAuth tokens, passwords, session cookies or unredacted files.
